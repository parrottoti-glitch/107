# اتوکلیکر اندروید

کلیک خودکار با دقت میلی‌ثانیه، زمان‌بندی شروع، ساعت دقیق NTP، نوار شناور پلی/استاپ و تم تاریک.

## امکانات
- فاصله‌ی بین کلیک‌ها به میلی‌ثانیه
- تعداد ضربه (دستی با + و −، صفر = بی‌نهایت)
- شروع زمان‌بندی‌شده (ساعت:دقیقه:ثانیه.میلی‌ثانیه)، مثلاً ۰۸:۳۰:۰۰.۰۵۰
- همگام‌سازی ساعت با سرور NTP و نمایش ساعت دقیق با میلی‌ثانیه
- پیش‌دستی (جبران تأخیر) به میلی‌ثانیه
- نوار شناور (▶ / ■ / ✕) و دایره‌ی هدف قابل جابه‌جایی

## بیلد
- گیت‌هاب: تب Actions → Build APK → فایل `AutoClicker-debug` را از Artifacts دانلود کن.
- یا در Android Studio: Build > Build APK.
(نیازمند Gradle 8.2 یا بالاتر و JDK 17)

## استفاده
1. APK را نصب کن و برنامه را باز کن.
2. «فعال‌سازی سرویس دسترسی» را بزن و اتوکلیکر را روشن کن.
3. «همگام‌سازی ساعت با NTP» را بزن (ساعت سبز رنگ، ساعت دقیق است).
4. تنظیمات را وارد کن و «نمایش نوار شناور و هدف» را بزن.
5. دایره‌ی قرمز را روی نقطه‌ی مورد نظر ببر و ▶ را بزن.

## نکته‌ها
- اگر تا شروع بیش از ۱۰ ثانیه مانده باشد، برنامه قبل از انتظار یک بار دیگر ساعت را با NTP هماهنگ می‌کند.
- فاصله‌های زیر حدود ۱۰ میلی‌ثانیه ممکن است روی بعضی گوشی‌ها دقیق اجرا نشوند.
- اگر زمان تنظیم‌شده گذشته باشد، برای فردا زمان‌بندی می‌شود.
- NTP از پورت UDP 123 استفاده می‌کند؛ بعضی شبکه‌ها آن را می‌بندند.
